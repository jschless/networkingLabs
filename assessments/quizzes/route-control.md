# Topic Quiz — Route Control & Redistribution

**Time:** 35 minutes · **Total:** 30 points · **Closed book, no CLI**

**Prerequisites:** `redistribution-tags`, `route-maps-pbr`, and `ip-sla-tracking`.
`ospf-bgp-redist` is recommended background.

Configuration syntax is Arista EOS as used by the labs.

---

## Section 1 — Mechanisms (6 points)

### A1 — PBR is outside the RIB (3 points)

Explain when interface policy-based routing runs relative to the normal destination
lookup, why it can select a path absent from the best route, and why it does not affect
traffic generated by the router itself. Name the separate mechanism for locally generated
traffic. (3 pts)

### A2 — What a probe adds (3 points)

Contrast an ordinary floating static route with an IP-SLA-tracked primary and floating
backup. Explain one failure a next-hop-only design misses and one way a badly chosen SLA
target can cause a false failover. (3 pts)

---

## Section 2 — Evidence reading (8 points)

### B1 — The RIB failed over; the user did not

host-b enters router Ethernet2 and should use ISP-B. ISP-B is down. The tracked routing
policy has correctly moved the default to ISP-A, but host-b still cannot reach the test
server.

```text
router# show ip route 0.0.0.0/0
S  0.0.0.0/0 [200/0] via 10.0.1.2, Ethernet1

router# show track 2
Track 2
  IP SLA 2 reachability
  State is Down

router# show ip policy
Interface Ethernet2: route-map PBR-ISP-B

router# show route-map PBR-ISP-B
route-map PBR-ISP-B permit 10
  match ip address HOST-B
  set ip next-hop 10.0.2.2
```

1. Explain why the healthy backup default does not save host-b traffic. (2 pts)
2. Give two defensible PBR repairs and the behavioral difference between them. (2 pts)
3. Why would deleting the backup default be irrelevant to this symptom? (1 pt)
4. Give three checks that prove the repaired behavior, including one route-map check and
   one end-host path check. (3 pts)

## Section 3 — Application (10 points)

### C1 — Tracked primary and floating backup (6 points)

Configure:

- IP SLA operation 1 to ICMP-probe `10.99.0.1` from `Ethernet1` every 5 seconds;
- the operation to run forever starting now;
- track object 1 bound to SLA reachability;
- primary default through `10.0.1.2`, AD 5, installed only while track 1 is Up;
- floating backup default through `10.0.2.2`, AD 200.

### C2 — Source-based PBR with reachability protection (4 points)

Traffic arriving on `Ethernet2` from `10.20.0.0/24` should prefer next hop `10.0.2.2`
only while that next hop is usable; otherwise it should fall back to normal routing.
Write the EOS ACL, route-map, and interface attachment.

---

## Section 4 — Redistribution safety (6 points)

### D1 — One boundary, one convention

OSPF and EIGRP meet at two ASBRs. Use the repository convention:

- tag 100 means “originated in OSPF and entered EIGRP”;
- tag 200 means “originated in EIGRP and entered OSPF.”

1. State the deny and set behavior required in each redistribution direction. (3 pts)
2. Explain why the policy must be identical at both ASBRs and why administrative distance
   alone is not loop prevention. (2 pts)
3. Name one piece of evidence in each protocol that proves returning routes are being
   rejected. (1 pt)
