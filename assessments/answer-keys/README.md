## What is in each key

- **Model answers** with the point split for every part.
- **Grading notes** calling out the specific misconception each question was built to catch,
  and what to do about a partially right answer. Where an answer is defensible in more than
  one direction, the key says so and tells you what earns the marks in each.
- **A remediation table** at the end mapping every question back to the lab that teaches it.
  This is the part worth reading carefully after marking: it turns a score into a study
  plan.

## Marking guidance

Two principles run through all five keys:

1. **Mechanism beats vocabulary.** A candidate who describes what happens and fumbles the
   command name is in better shape than one who recites the command and cannot say what it
   does. The keys allocate marks accordingly, and several questions withhold marks
   explicitly for naming a component where a mechanism was asked for.
2. **Method beats the right guess.** In the Section 5 narratives, an answer that reaches the
   wrong conclusion through disciplined elimination scores more than one that names the
   correct fault with no supporting reasoning — because only the first is repeatable on a
   fault nobody has seen before.

For proctored sittings, the red-flag caps from the
[troubleshooting range](../../labs/troubleshooting-range/ASSESSMENT.md) apply to Section 5:
an answer that masks a symptom rather than repairing its cause is capped regardless of raw
points, even when the symptom would genuinely disappear.
