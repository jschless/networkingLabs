# Ticket TR-207 — Corporate services path drift

**Reported by:** Network performance monitoring  
**Impact:** Corporate access to the services network remains available but is
using a longer redundant path and no longer meets the expected path policy.  
**Symptom:** The path changed immediately after interface maintenance. Links
and routed peers are up, and no similar drift is reported for other access
blocks.

Diagnose, fix, and verify the incident. Submit route-selection evidence, the
minimal correction, and proof that both reachability and the expected path are restored.
