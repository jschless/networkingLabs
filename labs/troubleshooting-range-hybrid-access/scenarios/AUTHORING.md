# Hybrid Access Scenario Authoring

Scenarios in this range follow
[`labs/troubleshooting-range/scenarios/AUTHORING.md`](../../troubleshooting-range/scenarios/AUTHORING.md).
The installed ticket-authoring skill also calls for
`labs/troubleshooting-range/references/range-routing.md`, but that reference is
absent from this repository. [`DESIGN.md`](../DESIGN.md) is the authoritative
replacement for this range's node/address map, healthy paths, safe runtime
mutations, and non-duplicate catalog.

The topology version is frozen only after the foundation's clean live validation.
Future scenario PRs may add exactly one cataloged scenario directory at a time;
they must not add nodes, links, or address families under the frozen version.
