# OT & IoT Networking Track

Safe, synthetic practice for enterprise-to-industrial boundaries. The live
mechanisms are network policy, protocol transactions, passive detection, evidence
correlation, and troubleshooting—not physical-process control.

| Lab | Type | What You Learn |
|---|---|---|
| [ot-zone-conduit](ot-zone-conduit.md) | Practice | Purdue-inspired zones, default-deny conduits, Modbus visibility, jump maintenance, and stale-historian diagnosis |

## Platform

Build the digest-pinned Linux tool image:

```bash
docker build -t ot-zone-tools:1.0.0 labs/ot-zone-conduit/
```

The lab has no licensed NOS or hardware dependency.
