# Debug Labs

Fifteen fully-working topologies, each with **one intentional bug**. The README gives you the scenario, symptoms, three-level hints, and the solution. Use these to practice structured troubleshooting.

!!! tip "How to use debug labs"
    1. Read the scenario and symptoms in the lab README
    2. Try to find the bug on your own
    3. Use Hint 1 if stuck — it narrows the area
    4. Use Hint 2 if still stuck — it points to the specific mechanism
    5. Hint 3 / Solution reveals the exact misconfiguration
